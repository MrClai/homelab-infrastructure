# Проверка API

## Создание заметки

POST /notes с текстом «Изучить Docker» вернул статус 201 и ответ: `{"id":2,"text":"Изучить Docker"}`.

## Чтение заметок

GET /notes вернул статус 200 и обе созданные заметки.

## Пустой текст

POST /notes с текстом из пробелов вернул статус 400 и сообщение «Текст заметки не может быть пустым».

## Проверка базы

GET /health вернул статус 200 при работающей базе и 503 после остановки контейнера PostgreSQL. После запуска базы статус снова стал 200.
